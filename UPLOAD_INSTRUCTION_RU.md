# Обновление репозитория «Испанский через истории» — Сезон 3

В комплекте находятся только файлы, которые нужно заменить. Сезоны 1–2, изображения, рабочие процессы GitHub Actions, программный код и `data/state.json` изменять не нужно.

## Состав комплекта

- `audio/season3/morning/day01.mp3` … `day30.mp3` — 30 новых утренних аудио;
- `audio/season3/practice/day01.mp3` … `day30.mp3` — 30 новых дневных аудио;
- `data/lessons-season3.json` — финальные публикации сезона 3;
- `data/audio_manifest-season3.json` — финальный аудиоманифест с Ясмин, Адрианом и Диего.

Всего для замены: 62 рабочих файла.

## Как загрузить через сайт GitHub

1. Скачайте и распакуйте архив `spanish-season3-repo-update.zip`.
2. Откройте репозиторий `spanish-course-publisher` на GitHub.
3. Убедитесь, что находитесь в корне репозитория, где видны папки `.github`, `audio`, `data`, `images` и `src`.
4. Нажмите **Add file → Upload files**.
5. Перетащите в окно GitHub папки `audio` и `data` из распакованного комплекта.
6. GitHub покажет файлы как изменённые. Проверьте, что пути начинаются с:
   - `audio/season3/morning/`;
   - `audio/season3/practice/`;
   - `data/lessons-season3.json`;
   - `data/audio_manifest-season3.json`.
7. В поле сообщения напишите: `Update Spanish Season 3 publications and audio`.
8. Нажмите **Commit changes**.

Важно: не загружайте внешнюю папку `season3_repo_update` целиком. В корне репозитория должны объединиться именно папки `audio` и `data`; дополнительная вложенная папка не нужна.

## Проверка после загрузки

### 1. Автоматическая проверка комплекта

1. Откройте **Actions**.
2. Выберите **Publish Spanish course**.
3. Нажмите **Run workflow**.
4. Выберите `slot: check`.
5. Нажмите **Run workflow**.
6. Дождитесь зелёной галочки.

В журнале должны появиться строки:

- `Сезон 3: 30 утренних MP3 и 30 дневных MP3`;
- `Сезон 3: 30 утренних и 30 дневных публикаций проверены по аудиоманифесту`;
- `Сезон 3: 30 ежедневных Telegram Poll и 6 итоговых Poll`.

### 2. Проверка в тестовом Telegram-канале

Откройте **Actions → Preview Spanish Course → Run workflow**. В поле `confirm` каждый раз вводите `PREVIEW`.

Проведите три проверки:

1. `slot: morning`, `season: 3`, `day: 1` — новое полезное правило и полный утренний диалог;
2. `slot: morning`, `season: 3`, `day: 29` — отдельный голос Диего;
3. `slot: practice`, `season: 3`, `day: 30` — пять фраз, включая `A la izquierda.`, и новый финальный Poll.

Тестовый запуск не изменяет `data/state.json` и не мешает официальной публикации.
